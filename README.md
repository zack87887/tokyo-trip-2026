## 一、第一次上線（全程用 iPhone，免費）

GitHub 是放程式和檔案的網站，它附帶一個免費的「網頁服務」（GitHub Pages）：把檔案放上去、按一個開關，就會給你一個網址。免費帳號的條件是倉庫要設成「公開」。

**0. 先讓手機拿到這三個檔**
電腦已經把三個檔複製到 iCloud 雲碟的「東京旅遊網站」資料夾。手機打開「檔案」App → iCloud 雲碟 → 東京旅遊網站，看得到三個檔就可以了。

**1. 登入 GitHub**
用 Safari 打開 `github.com`，登入你的帳號（zack87887）。

**2. 建一個新倉庫（放檔案的資料夾）**
- Safari 打開 `https://github.com/new`
- 「Repository name」填：`tokyo-trip-2026`（網址會用到這個名字，只能用英文、數字、減號）
- 選 **Public**（公開；免費帳號一定要選這個才能開網頁）
- 其他都不用勾，按最下面綠色的 **Create repository**

**3. 上傳三個檔**
- 建好後的頁面上，找到藍色小字 **uploading an existing file** 點下去
- 點 **choose your files** → 跳出選單選「瀏覽」→ iCloud 雲碟 → 東京旅遊網站 → 把三個檔都選起來 → 打開
- 等三個檔名都出現在清單裡，捲到最下面按綠色的 **Commit changes**（意思是「存檔」）

**4. 打開網頁服務**
- Safari 打開 `https://github.com/zack87887/tokyo-trip-2026/settings/pages`
  （也可以在倉庫頁面點 **Settings**；手機上可能藏在「…」選單裡，左側選單找 **Pages**）
- 「Build and deployment」底下的 **Source** 選 **Deploy from a branch**
- **Branch** 選 `main`，旁邊資料夾選 `/(root)`，按 **Save**
- 等一兩分鐘，重新整理這一頁，上方會出現網站已上線的提示和網址（第一次可能要等久一點）

**5. 分享給家人**
- 打開網址確認看得到，把網址貼到家族 LINE 群
- 家人可以在 Safari 按「分享」→「加入主畫面」，手機桌面就會有一個像 App 的圖示

## 二、行程變動怎麼改

### 最快：臨時公告（例如「明天集合改 07:10」）
打開 `trip-data.js`，找到最上面這行：

```js
公告: "",
```

在兩個引號中間打字，例如：

```js
公告: "12/4 集合改 07:10，在飯店大廳",
```

存檔後，網頁最上面會出現黃色公告。事情過了再改回 `公告: "",`。

### 改時間、景點、餐廳
1. Safari 打開倉庫 `https://github.com/zack87887/tokyo-trip-2026`
2. 點 `trip-data.js` → 點右上角的**鉛筆圖示**（Edit，編輯）
3. 往下找到要改的那天、那張卡片，只改雙引號 `" "` 裡面的字
4. 把最上面的 `更新日期` 改成今天
5. 按右上角綠色的 **Commit changes…** → 跳出視窗再按一次 **Commit changes**
6. 等一兩分鐘，家人重新整理網頁就會看到新內容（網頁每次打開都會重新抓最新行程）

### 新增一張卡片
找一張類似的卡片，從 `{` 複製到 `},`（包含結尾逗號），貼在它下面再改字。可以用的欄位寫在 `trip-data.js` 的「每日行程」說明區，例如 `必去: true` 會標上粉紅色「必去」、`集合: true` 會標上「集合」。

### 填航班
找到「航班」那段，每一批有「去程」「回程」兩欄，格式不一樣：

- 去程欄：`12/3（四）航班號碼 起飛時間 桃園 → 抵達時間 成田`
- 回程欄：`12/8（二）航班號碼 起飛時間 成田 → 抵達時間 桃園`

日期、出發與抵達機場以各批機票為準；不是桃園或成田就照實改。**只填航班號碼和時間**，不要填訂位代號、護照資料。

### 也可以直接跟藍哥說
跟藍哥說要改什麼（例如「把 12/6 晚餐改成 XXX」），藍哥會先整理好修改內容，照專案既定的複檢與核准流程，你點頭後才推上 GitHub。臨時急事（例如集合時間）建議先自己改「公告」那行，最快。

## 三、改的時候最容易出錯的三件事

1. **iPhone 會自動把引號變成彎的**（“ ”），網頁就讀不懂。
   改之前先關掉：iPhone「設定 → 一般 → 鍵盤 → 智慧型標點符號」→ 關。
2. **冒號、逗號要用半形**（`:` `,`），中文輸入法打出來的全形 `：` `，` 不行。
   （引號「裡面」的文字用全形沒問題，只有引號外面的符號要半形。）
3. **每段結尾的逗號不要刪掉。**

改壞了也不用慌：網頁會出現紅框，告訴你「trip-data.js 第幾行附近」有問題，回去照著修就好。真的修不好：
- 在 GitHub 打開 `trip-data.js`，點右上角的 **History**（時鐘圖示）看每次修改紀錄，點上一版、複製內容貼回來；或
- 直接叫藍哥處理。

## 四、隱私提醒

- 這是**公開**網址：拿到網址的人都看得到，也有機會被找到。網頁已經加了「請搜尋引擎不要收錄」的標記，但它不是密碼保護。
- 不要放：護照號碼、訂位代號、電話、家人全名、門票 QR code、住家地址。
- 「待辦清單」的打勾只記在各自的手機裡，不會同步給其他家人，換手機或清掉瀏覽紀錄就會消失。
